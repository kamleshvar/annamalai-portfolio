HOW HIDDEN RECORDS WORK

  • ARTIFACTThe first enabled artifact record is opened by the hero artifact scan.

  • DOCUMENT / HIDDENThese become floating archive nodes assigned to their section.
  • ACCESS FRAGMENTSlots 1–4 publish codes. The control console opens only after every published code is submitted in the Tempad terminal.
